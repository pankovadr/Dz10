### Алгоритм
1. **Начало**
2. Объявление переменных: a, b, h.
3. Запуск цикла do-while.
4. Ввод: Вывод меню на экран. Считывание выбора пользователя в переменную choice.
5. Ветвление:
 • Если choice == 1: Запросить a, b, h. Вызвать функцию area(a, b, h). Вывести результат на экран.
 • Иначе если choice == 2: Вывести на экран текст определения.
 • Иначе если choice == 3: Запросить целые a, b, h. Вызвать функцию draw(a, b, h).
 • Иначе если choice == 4: Запросить параметры для двух трапеций. Вызвать функцию compare(...).
6. Конец цикла: Возврат к шагу 3.
7. Конец программы: Возврат 0. 
Вспомогательная функция area(a, b, h):
1. Вычислить площадь по формуле: S = ((a + b) / 2) * h.
2. Вернуть значение S. 
Вспомогательная функция draw(a, b, h):
1. Запустить цикл i от 0 до h (для отрисовки строк).
2. Внутри цикла: вывести пробелы (отступ слева), вывести *, вывести пробелы (внутри), вывести * и перенос строки.
3. После цикла: вывести нижнее основание (цикл от 0 до a выводит *).
4. Перенос строки. 
Вспомогательная функция compare(...):
1. Вычислить площадь первой трапеции (s1).
2. Вычислить площадь второй трапеции (s2).
3. Вывести обе площади.
4. Сравнить: если s1 > s2 — вывести "Первая больше", иначе если s2 > s1 — "Вторая больше", иначе — "Они равны".
